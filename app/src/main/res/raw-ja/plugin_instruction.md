3-Chime Alarm は, AutoJs6 がなくても単独で使えるアラーム, タイマー, ストップウォッチのアプリです. アラームはカレンダーのルールで繰り返し, 祝日を避けたり祝日だけ鳴らしたりでき, 鳴動時にテキストを読み上げたり, 止める前にチャレンジの達成を求めたりできます. AutoJs6 と組み合わせると, スクリプトからアラームとタイマーを管理でき, 指定したスクリプトを鳴動などのイベントの発生時に自動で起動することもできます.

### はじめに

1. 3-Chime Alarm を開きます. ホーム画面に "アラームが正しく鳴らない可能性があります" という案内が表示されたら, 案内をタップし, "権限とバックグラウンド動作" ページで項目を順に設定します.
2. 右下の "新しいアラーム" ボタンをタップし, 時刻, 繰り返し, アラーム音を設定してから "保存" をタップします.
3. 下部のナビゲーションで "タイマー" または "ストップウォッチ" に切り替えます. 上部バーの "設定" ボタンをタップすると, アラーム音, バイブレーション, スヌーズなどの既定値を設定できます.
4. スクリプトで使うときは, AutoJs6 の "プラグインセンター" でこのプラグインを有効にします.

### 主な機能

- **繰り返し**: "毎日", "月曜日から金曜日", "週末", "曜日を選択" から選べます. "詳細ルール" は毎月第何週の何曜日, 月末, 何日おきなどのカレンダーのルールに対応し, "スキップする日付" も追加できます.
- **鳴動**: システムのサウンドまたは取り込んだローカルの音声ファイルを使え, "読み上げ" のテキスト, バイブレーション, スヌーズを設定できます. ロック画面では全画面の鳴動画面を表示し, 同時に時刻になった複数のアラームは順番に鳴ります.
- **祝日**: 編集ページの "祝日" の行で "祝日は鳴らさない", "祝日のみ鳴らす", "勤務日のみ鳴らす" (振替出勤日も鳴る) を選べます. 250 の国と地域のデータを内蔵し, 更新は毎週自動で確認します.
- **停止チャレンジ**: "停止チャレンジ" の行で, アラームを止める前に "計算問題", "振る", "テキスト入力" のいずれかの達成を求められます. どのチャレンジにも "自動停止" と "緊急停止" の 2 つの逃げ道があります.
- **タイマーとストップウォッチ**: 最大 20 個のタイマーを同時に動かせ, 通知から直接 "一時停止", "+1 分", "キャンセル" を操作できます. ストップウォッチは "ラップ" を記録でき, 最速と最遅のラップに印を付けます.
- **時間どおりに鳴る**: 再起動, 時刻やタイムゾーンの変更の後は自動でスケジュールし直し, 起動後のロック解除前でも鳴ります. 電源オフ中に逃したアラームは, 5 分以内に電源を入れれば遅れて鳴り, それ以外は通知を残します.
- **システムの時計リクエスト**: カレンダーや音声アシスタントなど他のアプリからの, アラームの設定, タイマーの設定, アラームの停止などのリクエストを処理できます.
- **表示の設定**: "言語", "ナイトモード", "テーマ色" は既定で AutoJs6 に従い, 設定で個別に指定することもできます. "ランチャーアイコン" も切り替えられます.
- **プラグインツール**: MCP Server プラグインまたは `plugins.tools.call` から, アラームの作成, 照会, 変更, タイマーの操作, 祝日の照会ができます.

### スクリプトでの使い方

AutoJs6 の Rhino スクリプトでは, グローバルモジュール `alarms` でアラームとタイマーを使います. 次の例は平日 7:30 のアラームを作成し, アラームを止めたときに実行するスクリプトを登録してから, 25 分のタイマーを開始します:

```js
let a = alarms.add({ time: '07:30', repeat: [1, 2, 3, 4, 5], label: '起床' });
console.log(a.repeatText, new Date(a.nextTrigger));
a.bind('./after-wake.js', { events: ['dismiss'] });

let t = alarms.timers.start('25m', { label: 'ポモドーロ' });
console.log(t.id, new Date(t.endsAt).toLocaleTimeString());
```

- スクリプトで作成したアラームとタイマーもプラグインの画面に表示され, 画面で変更できます. スクリプトから, 画面で作成したアラームを読み書きすることもできます.
- `bind` で登録したスクリプトはイベントの発生時に AutoJs6 が起動するため, 常駐させる必要はありません. 実行中のスクリプトは `alarms.on('ring', ...)` でリアルタイムに監視できます.
- Node.js と Bun のスクリプトには `alarms` モジュールがありません. `engines.execScript` で, これを使う Rhino スクリプトを実行できます.
- 祝日, 鳴動前のスクリプトによる判断, 停止チャレンジなどの詳しい使い方は [AutoJs6 ドキュメント > alarms](https://docs.autojs6.com/#/alarms) を参照してください.

### 動作要件

- Android 7.0 以降. アラーム, タイマー, ストップウォッチには AutoJs6 は不要です.
- `alarms` モジュールとプラグインツールには AutoJs6 6.8.1 以降が必要で, "プラグインセンター" でこのプラグインを有効にする必要があります.
- 正確なアラームの権限は時間どおりに鳴らすために使い, Android 12 と 12L ではシステム設定で "アラームとリマインダー" を許可する必要があります. 通知の権限は鳴動と実行中のタイマーの表示に使います.
- 全画面通知の権限はロック画面に鳴動画面を表示するために使います. 他のアプリの上に重ねて表示する権限は任意で, システムが全画面通知を表示しないときに鳴動画面を開くために使います.
- システムがバックグラウンドでプラグインを停止しないよう, "権限とバックグラウンド動作" ページで電池の最適化をオフにし, バックグラウンドの制限を解除し, 自動起動を許可することをおすすめします.

### よくある質問

**AutoJs6 が動いていないときの鳴動**

アラームはプラグイン自身がスケジュールするため, AutoJs6 が動いていなくても通常どおり鳴ります. 登録したスクリプトは, プラグインが AutoJs6 を起こして起動します. AutoJs6 が強制停止された後は, AutoJs6 をもう一度開くまでスクリプトは起動しません.

**AutoJs6 6.8.0 のプラグインセンターでこのプラグインを有効にできない理由**

プラグインセンターでこのプラグインを有効にするには AutoJs6 6.8.1 以降が必要です. それより前の AutoJs6 でも, このプラグインは単独のアラームアプリとして使えます.

**アラームが時間どおりに鳴らないときの対処**

ホーム画面の案内をタップし, "権限とバックグラウンド動作" ページで項目を順に設定します. ColorOS では同じページの "自動起動リスト" の行も設定します. プラグインが強制停止されると時刻になったアラームは鳴りませんが, プラグインを一度開けば元に戻ります.

**停止チャレンジを達成できないときの対処**

鳴動画面が前面にあるとき (ロック画面上を含む), 4 秒以内に音量キーを 5 回押すと緊急停止できます. この機能は設定でオフにできます. それ以外の場合, アラームは自動停止の時間が過ぎると止まり, 個別に設定していなければ少なくとも 30 分です.

権限, システムの時計リクエスト, 祝日データの詳細は [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Chime-Alarm) を参照してください.
