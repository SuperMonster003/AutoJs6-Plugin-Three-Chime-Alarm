3-Chime Alarm 是鬧鐘, 計時器與秒錶應用程式, 不安裝 AutoJs6 也能獨立使用. 鬧鐘可以按日曆規則重複, 避開節假日或只在節假日響, 響鈴時可以朗讀文字, 也可以要求先完成一項挑戰才能關閉. 配合 AutoJs6 時, 腳本可以管理鬧鐘與計時器, 指定的腳本亦可以在響鈴等事件發生時自動啟動.

### 開始使用

1. 打開 3-Chime Alarm. 主頁出現 "鬧鐘可能無法正常響鈴" 的提示時, 點按提示, 在 "權限與後台運行" 頁逐項處理.
2. 點按右下角的 "新增鬧鐘" 按鈕, 設定時間, 重複與鈴聲, 然後點按 "儲存".
3. 用底部導覽列切換到 "計時器" 或 "秒錶"; 點按頂欄的 "設定" 按鈕, 可以設定鈴聲, 震動與貪睡等預設值.
4. 需要在腳本中使用時, 在 AutoJs6 的 "插件中心" 啟用本插件.

### 主要功能

- **重複**: 可以選 "每天", "星期一至星期五", "週末" 或 "自選星期"; "進階規則" 支援每月第幾個星期幾, 月底, 間隔天數等日曆規則, 亦可以加入 "略過的日期".
- **響鈴**: 可以使用系統鈴聲或匯入的本地音訊, 設定 "朗讀" 的文字, 震動與貪睡; 鎖屏時顯示全屏響鈴介面, 多個鬧鐘同時到時依次響鈴.
- **節假日**: 編輯頁的 "節假日" 一行可以選 "節假日不響", "只在節假日響" 或 "只在工作日響" (補班日亦響). 內置 250 個國家和地區的數據, 每週自動檢查更新.
- **關閉挑戰**: "關閉挑戰" 一行可以要求先完成 "算術題", "搖動" 或 "輸入文字" 才能關閉鬧鐘. 每種挑戰都保留 "自動停止" 與 "緊急關閉" 兩條出路.
- **計時器與秒錶**: 最多 20 個計時器同時運行, 可以在通知欄直接 "暫停", "+1 分鐘" 或 "取消"; 秒錶可以 "計圈", 並標出最快與最慢的一圈.
- **準時可靠**: 裝置重新開機, 修改時間或時區後自動重新排程, 開機後未解鎖也會響鈴; 關機時錯過的鬧鐘在過時 5 分鐘內開機會補響, 否則留下一條通知.
- **系統時鐘請求**: 可以處理日曆, 語音助理等其他應用程式發出的設定鬧鐘, 設定計時器與關閉鬧鐘等請求.
- **介面設定**: "語言", "夜間模式" 與 "主題色" 預設跟隨 AutoJs6, 亦可以在設定中單獨設定; 還可以切換 "啓動器圖標".
- **插件工具**: 透過 MCP Server 插件或 `plugins.tools.call` 新增, 查詢與修改鬧鐘, 控制計時器與查詢節假日.

### 在腳本中使用

在 AutoJs6 的 Rhino 腳本中透過全域模組 `alarms` 使用鬧鐘與計時器. 下例新增一個工作日 7:30 的鬧鐘, 登記關閉鬧鐘時運行的腳本, 再開始一個 25 分鐘的計時器:

```js
let a = alarms.add({ time: '07:30', repeat: [1, 2, 3, 4, 5], label: '起床' });
console.log(a.repeatText, new Date(a.nextTrigger));
a.bind('./after-wake.js', { events: ['dismiss'] });

let t = alarms.timers.start('25m', { label: '番茄鐘' });
console.log(t.id, new Date(t.endsAt).toLocaleTimeString());
```

- 腳本建立的鬧鐘與計時器同樣顯示在插件介面中, 可以在介面中修改; 腳本亦可以讀寫在介面中建立的鬧鐘.
- 用 `bind` 登記的腳本在事件發生時由 AutoJs6 啟動, 不必常駐; 正在運行的腳本可以用 `alarms.on('ring', ...)` 即時監聽.
- Node.js 與 Bun 腳本中沒有 `alarms` 模組, 可以用 `engines.execScript` 運行一個使用它的 Rhino 腳本.
- 節假日, 響鈴前由腳本決定與關閉挑戰等完整用法見 [AutoJs6 文檔 > alarms](https://docs.autojs6.com/#/alarms).

### 運行要求

- Android 7.0 或更高版本. 鬧鐘, 計時器與秒錶不需要 AutoJs6.
- `alarms` 模組與插件工具需要 AutoJs6 6.8.1 或更高版本, 並在 "插件中心" 啟用本插件.
- 精確鬧鐘權限用於準時響鈴, Android 12 與 12L 需要在系統設定中允許 "鬧鐘和提醒"; 通知權限用於顯示響鈴與運行中的計時器.
- 全屏提醒權限用於在鎖屏上顯示響鈴介面; 懸浮視窗權限為可選, 在系統不顯示全屏提醒時用來打開響鈴介面.
- 建議在 "權限與後台運行" 頁關閉電池優化, 解除後台限制並允許自動啟動, 以免系統在後台停止插件.

### 常見問題

**AutoJs6 未運行時的響鈴**

鬧鐘由插件自行排程, AutoJs6 未運行時照常響鈴. 登記的腳本由插件喚醒 AutoJs6 啟動; AutoJs6 被強制停止後, 在再次打開 AutoJs6 之前腳本不會啟動.

**AutoJs6 6.8.0 的插件中心無法啟用本插件的原因**

插件中心啟用本插件需要 AutoJs6 6.8.1 或更高版本. 在更早的 AutoJs6 上, 本插件仍可以作為獨立的鬧鐘應用程式使用.

**鬧鐘沒有準時響鈴時的處理**

點按主頁的提示, 在 "權限與後台運行" 頁逐項處理; ColorOS 上還要處理同一頁的 "自動啟動列表" 一行. 插件被強制停止後, 到時的鬧鐘不會響, 打開一次插件即可恢復.

**關閉挑戰無法完成時的處理**

響鈴介面在前台時 (包括在鎖屏上), 4 秒內按 5 次音量鍵即可緊急關閉, 此功能可以在設定中關閉. 否則鬧鐘在自動停止的時長過後停止, 未單獨設定時至少 30 分鐘.

權限說明, 系統時鐘請求與節假日數據的詳情見 [項目主頁](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Chime-Alarm).
