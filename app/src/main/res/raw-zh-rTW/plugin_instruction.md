3-Chime Alarm 是鬧鐘, 計時器與碼錶應用程式, 不安裝 AutoJs6 也能獨立使用. 鬧鐘可以依日曆規則重複, 避開節假日或只在節假日響, 響鈴時可以朗讀文字, 也可以要求先完成一項挑戰才能關閉. 搭配 AutoJs6 時, 指令碼可以管理鬧鐘與計時器, 指定的指令碼也可以在響鈴等事件發生時自動啟動.

### 開始使用

1. 開啟 3-Chime Alarm. 主頁出現 "鬧鐘可能無法正常響鈴" 的提示時, 點按提示, 在 "權限與背景執行" 頁逐項處理.
2. 點按右下角的 "新增鬧鐘" 按鈕, 設定時間, 重複與鈴聲, 然後點按 "儲存".
3. 用底部導覽列切換到 "計時器" 或 "碼錶"; 點按頂端列的 "設定" 按鈕, 可以設定鈴聲, 震動與貪睡等預設值.
4. 需要在指令碼中使用時, 在 AutoJs6 的 "外掛中心" 啟用本外掛.

### 主要功能

- **重複**: 可以選 "每天", "週一至週五", "週末" 或 "自選星期"; "進階規則" 支援每月第幾個星期幾, 月底, 間隔天數等日曆規則, 也可以加入 "略過的日期".
- **響鈴**: 可以使用系統鈴聲或匯入的本機音訊, 設定 "朗讀" 的文字, 震動與貪睡; 鎖定螢幕時顯示全螢幕響鈴畫面, 多個鬧鐘同時到時依序響鈴.
- **節假日**: 編輯頁的 "節假日" 一列可以選 "節假日不響", "只在節假日響" 或 "只在工作日響" (補班日也響). 內建 250 個國家和地區的資料, 每週自動檢查更新.
- **關閉挑戰**: "關閉挑戰" 一列可以要求先完成 "算術題", "搖動" 或 "輸入文字" 才能關閉鬧鐘. 每種挑戰都保留 "自動停止" 與 "緊急關閉" 兩條出路.
- **計時器與碼錶**: 最多 20 個計時器同時執行, 可以在通知欄直接 "暫停", "+1 分鐘" 或 "取消"; 碼錶可以 "計圈", 並標出最快與最慢的一圈.
- **準時可靠**: 裝置重新開機, 修改時間或時區後自動重新排程, 開機後未解鎖也會響鈴; 關機時錯過的鬧鐘在過時 5 分鐘內開機會補響, 否則留下一則通知.
- **系統時鐘請求**: 可以處理行事曆, 語音助理等其他應用程式發出的設定鬧鐘, 設定計時器與關閉鬧鐘等請求.
- **介面設定**: "語言", "夜間模式" 與 "主題色" 預設跟隨 AutoJs6, 也可以在設定中單獨設定; 還可以切換 "啟動器圖示".
- **外掛工具**: 透過 MCP Server 外掛或 `plugins.tools.call` 新增, 查詢與修改鬧鐘, 控制計時器與查詢節假日.

### 在指令碼中使用

在 AutoJs6 的 Rhino 指令碼中透過全域模組 `alarms` 使用鬧鐘與計時器. 下例新增一個工作日 7:30 的鬧鐘, 登記關閉鬧鐘時執行的指令碼, 再開始一個 25 分鐘的計時器:

```js
let a = alarms.add({ time: '07:30', repeat: [1, 2, 3, 4, 5], label: '起床' });
console.log(a.repeatText, new Date(a.nextTrigger));
a.bind('./after-wake.js', { events: ['dismiss'] });

let t = alarms.timers.start('25m', { label: '番茄鐘' });
console.log(t.id, new Date(t.endsAt).toLocaleTimeString());
```

- 指令碼建立的鬧鐘與計時器同樣顯示在外掛介面中, 可以在介面中修改; 指令碼也可以讀寫在介面中建立的鬧鐘.
- 用 `bind` 登記的指令碼在事件發生時由 AutoJs6 啟動, 不必常駐; 正在執行的指令碼可以用 `alarms.on('ring', ...)` 即時監聽.
- Node.js 與 Bun 指令碼中沒有 `alarms` 模組, 可以用 `engines.execScript` 執行一個使用它的 Rhino 指令碼.
- 節假日, 響鈴前由指令碼決定與關閉挑戰等完整用法見 [AutoJs6 文件 > alarms](https://docs.autojs6.com/#/alarms).

### 執行需求

- Android 7.0 或更高版本. 鬧鐘, 計時器與碼錶不需要 AutoJs6.
- `alarms` 模組與外掛工具需要 AutoJs6 6.8.1 或更高版本, 並在 "外掛中心" 啟用本外掛.
- 精確鬧鐘權限用於準時響鈴, Android 12 與 12L 需要在系統設定中允許 "鬧鐘與提醒"; 通知權限用於顯示響鈴與執行中的計時器.
- 全螢幕提醒權限用於在鎖定畫面上顯示響鈴畫面; 懸浮視窗權限為選用, 在系統不顯示全螢幕提醒時用來開啟響鈴畫面.
- 建議在 "權限與背景執行" 頁關閉電池最佳化, 解除背景限制並允許自動啟動, 以免系統在背景停止外掛.

### 常見問題

**AutoJs6 未執行時的響鈴**

鬧鐘由外掛自行排程, AutoJs6 未執行時照常響鈴. 登記的指令碼由外掛喚醒 AutoJs6 啟動; AutoJs6 被強制停止後, 在再次開啟 AutoJs6 之前指令碼不會啟動.

**AutoJs6 6.8.0 的外掛中心無法啟用本外掛的原因**

外掛中心啟用本外掛需要 AutoJs6 6.8.1 或更高版本. 在更早的 AutoJs6 上, 本外掛仍可以作為獨立的鬧鐘應用程式使用.

**鬧鐘沒有準時響鈴時的處理**

點按主頁的提示, 在 "權限與背景執行" 頁逐項處理; ColorOS 上還要處理同一頁的 "自動啟動清單" 一列. 外掛被強制停止後, 到時的鬧鐘不會響, 開啟一次外掛即可恢復.

**關閉挑戰無法完成時的處理**

響鈴畫面在前景時 (包括在鎖定畫面上), 4 秒內按 5 次音量鍵即可緊急關閉, 此功能可以在設定中關閉. 否則鬧鐘在自動停止的時長過後停止, 未單獨設定時至少 30 分鐘.

權限說明, 系統時鐘請求與節假日資料的詳情見 [專案主頁](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Chime-Alarm).
