3-Chime Alarm 是闹钟, 计时器与秒表应用, 不装 AutoJs6 也能单独使用. 闹钟可以按日历规则重复, 避开节假日或只在节假日响, 响铃时可以朗读文字, 也可以要求先完成一项挑战才能关闭. 配合 AutoJs6 时, 脚本可以管理闹钟与计时器, 指定的脚本也可以在响铃等事件发生时自动启动.

### 开始使用

1. 打开 3-Chime Alarm. 主页出现 "闹钟可能无法正常响铃" 的提示时, 点按提示, 在 "权限与后台运行" 页逐项处理.
2. 点按右下角的 "新建闹钟" 按钮, 设置时间, 重复与铃声, 然后点按 "保存".
3. 用底部导航切换到 "计时器" 或 "秒表"; 点按顶栏的 "设置" 按钮, 可以设定铃声, 振动与贪睡等默认值.
4. 需要在脚本中使用时, 在 AutoJs6 的 "插件中心" 启用本插件.

### 主要功能

- **重复**: 可以选 "每天", "周一至周五", "周末" 或 "自选星期"; "高级规则" 支持每月第几个星期几, 月末, 间隔天数等日历规则, 还可以添加 "跳过的日期".
- **响铃**: 可以用系统铃声或导入的本地音频, 设置 "朗读" 的文字, 振动与贪睡; 锁屏时显示全屏响铃界面, 多个闹钟同时到期时依次响铃.
- **节假日**: 编辑页的 "节假日" 一行可以选 "节假日不响", "只在节假日响" 或 "只在工作日响" (补班日也响). 内置 250 个国家和地区的数据, 每周自动检查更新.
- **关闭挑战**: "关闭挑战" 一行可以要求先完成 "算术题", "摇动" 或 "输入文字" 才能关闭闹钟. 每种挑战都保留 "自动停止" 与 "紧急关闭" 两条出路.
- **计时器与秒表**: 最多 20 个计时器同时运行, 可以在通知栏直接 "暂停", "+1 分钟" 或 "取消"; 秒表可以 "计圈", 并标出最快与最慢的一圈.
- **准时可靠**: 设备重启, 修改时间或时区后自动重新排程, 开机后未解锁也会响铃; 关机时错过的闹钟在过点 5 分钟内开机会补响, 否则留下一条通知.
- **系统时钟请求**: 可以处理日历, 语音助手等其他应用发出的设置闹钟, 设置计时器与关闭闹钟等请求.
- **界面设置**: "语言", "夜间模式" 与 "主题色" 默认跟随 AutoJs6, 也可以在设置中单独设定; 还可以切换 "启动器图标".
- **插件工具**: 通过 MCP Server 插件或 `plugins.tools.call` 新建, 查询与修改闹钟, 控制计时器与查询节假日.

### 在脚本中使用

在 AutoJs6 的 Rhino 脚本中通过全局模块 `alarms` 使用闹钟与计时器. 下例新建一个工作日 7:30 的闹钟, 登记关闭闹钟时运行的脚本, 再开始一个 25 分钟的计时器:

```js
let a = alarms.add({ time: '07:30', repeat: [1, 2, 3, 4, 5], label: '起床' });
console.log(a.repeatText, new Date(a.nextTrigger));
a.bind('./after-wake.js', { events: ['dismiss'] });

let t = alarms.timers.start('25m', { label: '番茄钟' });
console.log(t.id, new Date(t.endsAt).toLocaleTimeString());
```

- 脚本建的闹钟与计时器同样显示在插件界面中, 可以在界面中修改; 脚本也可以读写在界面中建的闹钟.
- 用 `bind` 登记的脚本在事件发生时由 AutoJs6 启动, 不必常驻; 正在运行的脚本可以用 `alarms.on('ring', ...)` 实时监听.
- Node.js 与 Bun 脚本中没有 `alarms` 模块, 可以用 `engines.execScript` 运行一个使用它的 Rhino 脚本.
- 节假日, 响铃前由脚本决定与关闭挑战等完整用法见 [AutoJs6 文档 > alarms](https://docs.autojs6.com/#/alarms).

### 运行要求

- Android 7.0 或更高版本. 闹钟, 计时器与秒表不需要 AutoJs6.
- `alarms` 模块与插件工具需要 AutoJs6 6.8.1 或更高版本, 并在 "插件中心" 启用本插件.
- 精确闹钟权限用于按时响铃, Android 12 与 12L 需要在系统设置中允许 "闹钟和提醒"; 通知权限用于显示响铃与运行中的计时器.
- 全屏提醒权限用于在锁屏上显示响铃界面; 悬浮窗权限为可选, 在系统不显示全屏提醒时用来打开响铃界面.
- 建议在 "权限与后台运行" 页关闭电池优化, 解除后台限制并允许自启动, 以免系统在后台停止插件.

### 常见问题

**AutoJs6 未运行时的响铃**

闹钟由插件自行调度, AutoJs6 未运行时照常响铃. 登记的脚本由插件唤醒 AutoJs6 启动; AutoJs6 被强行停止后, 在再次打开 AutoJs6 之前脚本不会启动.

**AutoJs6 6.8.0 的插件中心无法启用本插件的原因**

插件中心启用本插件需要 AutoJs6 6.8.1 或更高版本. 在更早的 AutoJs6 上, 本插件仍可以作为独立的闹钟应用使用.

**闹钟没有按时响铃时的处理**

点按主页的提示, 在 "权限与后台运行" 页逐项处理; ColorOS 上还要处理同一页的 "自动启动列表" 一行. 插件被强行停止后, 到点的闹钟不会响, 打开一次插件即可恢复.

**关闭挑战无法完成时的处理**

响铃界面在前台时 (包括在锁屏上), 4 秒内按 5 次音量键即可紧急关闭, 此功能可以在设置中关闭. 否则闹钟在自动停止的时长过后停止, 未单独设定时至少 30 分钟.

权限说明, 系统时钟请求与节假日数据的详情见 [项目主页](https://github.com/SuperMonster003/AutoJs6-Plugin-Three-Chime-Alarm).
